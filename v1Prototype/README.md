# AI Procurement OS V1 — Real Tender Test Prototype

Open index.html in a browser.

This prototype implements the first usable frontend slice:
- Executive Command Centre
- Tender Digital Twin
- Compliance Matrix
- Form Intelligence
- BOQ & Pricing War Room
- Submission Builder
- Company DNA / Evidence Locker
- Tender Copilot-style brief
- Human approval gate

Test tender: City of Tshwane Q02-01-2026-27.

It is a prototype, not production software. It has no live database, authentication, AI API, OCR, e-tender integration, accounting integration, or WhatsApp integration yet.
